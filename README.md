# A/B- тест в EdTech

## Цель проекта
В ходе тестирования одной гипотезы целевой группе была предложена новая механика оплаты услуг на сайте, у контрольной группы оставалась базовая механика. Необходимо проанализировать итоги эксперимента и сделать вывод, стоит ли запускать новую механику оплаты на всех пользователей.

## Стек
Python (pandas, numpy, seaborn, matplotlib, plotly, scipy, bootstrap), SQL (PostgreSQL, CLickHouse)/Redash (сложные запросы,  CTE), Git

## Этапы работы 
### В первом блоке A/B тестирование (Python):
1. Проведена предварительная обработка и анализ данных
2. Сформированы выборки для проведения анализа
3. Выполнен расчет ключевых метрик и визуализация по группам (CR, ARPU, ARPPU) 
4. Произведена проверка гипотез (Bootstrap, Welch's t-test) (upd: в финальном варианте 2.0 пришлось упростить решение и отказаться от bootstrap, так как это излишне, лучше не использовать 2 стат. теста и можно остановиться на Уэлче)
5. Подведены итоги и сделаны выводы по блоку
### Второй блок (SQL):
1. Выполнен поиск самых активных пользователей
2. Проведена оптимизация воронки (все метрики по группам с помощью CTE)
### Третий блок (Python): 
1. Реализована функция для автоматической подгрузки, обновления данных и расчету метрик
2. Реализована функция для визаулизации датафрейма с полученными метриками
